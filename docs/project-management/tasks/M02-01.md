- Thêm Prisma CLI và `@prisma/client` tương thích cùng một major version. Ưu tiên Prisma 6.x theo assumptions của ERD; pin version cụ thể, không dùng `latest`, ghi version trong báo cáo.

## 5. Security requirements — bắt buộc

- Không commit `.env`, secrets, JWT keys, database credentials, refresh token, password/hash mẫu hoặc dữ liệu khách hàng.
- Database URL chỉ lấy từ environment; validate cấu hình khi khởi động; không log URL/credentials.
- Least privilege: tách quyền migration owner khỏi runtime DB user nếu cấu hình môi trường cho phép; runtime user không cần quyền DDL.
- Mật khẩu admin hash Argon2id ở application layer (NFR-006); DB chỉ lưu encoded hash. Không tự đặt plaintext/password mặc định.
- Refresh token lưu SHA-256/HMAC hash phù hợp với thiết kế token; token rotation, one-time use, revokedAt/expiry, reuse detection và revoke toàn bộ sessions khi phát hiện reuse.
- Unique/constraint validation ở DB là lớp cuối; không chỉ dựa vào DTO/service.
- Không lưu card data (NFR-019); không log PII/token/secret; audit metadata tối thiểu cần thiết.
- Mọi thao tác xóa phải tuân thủ RESTRICT/CASCADE cụ thể trong ERD và decision log; product đã xuất hiện trong order không được hard delete.
- Migration phải review thủ công, không dùng `db push` thay migrations; không chạy migration trên production/staging.
- Không hạ security để test pass. Dùng database test riêng và dữ liệu giả có ghi nhãn test-only.
