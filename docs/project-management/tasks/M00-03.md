## Mục tiêu

Thống nhất TypeScript strict và quy ước code dùng chung toàn monorepo.

## Quyết định đã duyệt

- TypeScript `strict: true` ở mọi app/package (xem `tsconfig.base.json`).
- Prettier: 2 spaces, semicolons, double quotes, trailing commas.
- ESLint config dùng chung trong `packages/eslint-config/`.

## Phạm vi được phép sửa

`tsconfig.base.json`, `packages/typescript-config/` (`base.json`,
`nextjs.json`, `nestjs.json`), `packages/eslint-config/` (`base.js`,
`next.js`, `nest.js`), `.prettierrc.json`, `.prettierignore`, và
`tsconfig.json` của từng app (extend config dùng chung).

## Yêu cầu kỹ thuật

- `tsconfig.base.json`: target ES2022, module ESNext/bundler cho web,
  CommonJS cho NestJS (qua `nestjs.json` với `emitDecoratorMetadata` và
  `experimentalDecorators`).
- `nextjs.json`: jsx preserve, plugin `next`, `noEmit`.
- Frontend/admin `tsconfig.json` extend `nextjs.json`, có paths `@/*`,
  `@seecarauto/shared`, `@seecarauto/ui`.
- Backend `tsconfig.json` extend `nestjs.json`, `outDir: dist`.
- Quy ước code đầy đủ ghi trong `CODING_STANDARDS.md`.

## Tiêu chí nghiệm thu

1. Có quy định coding convention (file `CODING_STANDARDS.md`).
2. `pnpm typecheck` đạt toàn workspace.
3. `pnpm lint` đạt toàn workspace.

## Cách kiểm thử

- `pnpm typecheck`, `pnpm lint`, `pnpm format:check` ở root.
