## Mục tiêu

Viết README và tài liệu dự án đủ để người mới (và cuộc chat task mới)
chạy được dự án local mà không cần hỏi lại.

## Quyết định đã duyệt

- Project Handbook trong `docs/project-management/` là nguồn sự thật chung.

## Phạm vi được phép sửa

`README.md` (gốc), `docs/README.md`, `infrastructure/docker/README.md`.

## Yêu cầu kỹ thuật

- `README.md` ghi: vai trò, kiến trúc đã duyệt, cấu trúc thư mục, cách
  chạy local (pnpm và Docker), bảng lệnh thường dùng, quy tắc code tóm
  tắt, roadmap, và lưu ý Docker runtime UNVERIFIED trên máy Muse.
- `docs/README.md` liệt kê toàn bộ Project Handbook và tài liệu sẽ bổ sung
  ở các milestone sau (PRD/SRS, ERD, API Specification, Sitemap,
  Wireframe).
- Hướng dẫn chạy local phải đúng với lệnh thật đã kiểm tra
  (`pnpm install`, `pnpm build`, `pnpm dev`, `docker compose up`).

## Tiêu chí nghiệm thu

1. Có `docs/` và `README.md`.
2. Có hướng dẫn chạy dự án local (đúng lệnh thật).
3. Mọi đường dẫn tài liệu trong README đều tồn tại trong repo.

## Cách kiểm thử

- Đọc lại README và làm theo từng bước trên máy sạch (hoặc kiểm tra chéo
  với lệnh đã chạy trong M00).
