## 2. Mục tiêu

Thiết kế cấu trúc khu vực quản trị (Admin Dashboard) của website SeeCar Auto: sitemap riêng cho admin, cấu trúc sidebar/header/breadcrumb/điều hướng, wireframe Dashboard tổng quan, cấu trúc các module quản trị (sản phẩm, SKU, danh mục, thương hiệu, hãng xe, fitment, đơn hàng), cấu trúc quản lý người dùng, vai trò và quyền RBAC, cấu trúc quản lý bài viết, SEO, audit log và cài đặt, trạng thái giao diện theo quyền truy cập (loading, empty, error, forbidden) — đối chiếu với PRD, SRS, ERD và API Specification đã nghiệm thu.

## 3. Phạm vi

- Sitemap admin (ứng dụng admin riêng, Next.js, port 3001 — không phải đường dẫn `/admin/...` trong website khách hàng).
- Cấu trúc điều hướng: sidebar theo module, header, breadcrumb, hiển thị theo quyền.

## 8. Ghi chú thiết kế

- **Ứng dụng admin riêng:** admin là ứng dụng Next.js riêng (port 3001), gọi cùng backend `/api/v1` (INT-002). URL trong sitemap admin là đường dẫn trong ứng dụng admin (`/dashboard`, `/products`, …), KHÔNG có tiền tố `/admin` — tiền tố `/admin` chỉ xuất hiện trong đường dẫn API backend (`GET /api/v1/admin/dashboard/summary`), không phải URL giao diện.
- **Quyền là trung tâm:** mọi màn hình admin ghi rõ permission code yêu cầu (theo API_SPEC §6 + `x-required-permission` trong OpenAPI). Sidebar chỉ hiển thị module tài khoản có quyền xem; frontend chỉ ẩn nút, backend luôn kiểm tra (ADR-005).
- **Ma trận RBAC:** hành động trong ma trận theo FR-080 (View/Create/Update/Delete/Export/Cancel/Manage…); permission code thực tế trong API chỉ có view/create/update/delete/confirm/cancel (+ `*` cho auth) — Export/Manage có trong giao diện ma trận theo FR-080 nhưng chưa có endpoint nào dùng (ghi rõ là gap, M02/M03 chốt).
- **Dashboard chỉ số thật:** `GET /admin/dashboard/summary` trả số liệu thật; chưa có dữ liệu → `empty: true`; trường không có quyền → `null` + `hiddenByPermission: true` (FR-077).
- **Modal/toast:** mọi thao tác thêm/sửa mở modal (ADR-009); thành công/thất bại báo bằng toast/popup; xóa có xác nhận (PRD §6.5).
- **Cài đặt (đề xuất):** không có FR nào về Cài đặt trong PRD/SRS; mục Cài đặt trong sitemap là đề xuất cấu trúc (General, Payments, SEO defaults) — nội dung thật (tên cửa hàng, hotline, tài khoản ngân hàng) chờ Henry cung cấp; không bịa giá trị mặc định thành dữ liệu thật.
