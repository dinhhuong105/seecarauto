## Mục tiêu

Đóng gói toàn bộ hệ thống bằng Docker: Dockerfile riêng cho từng app,
`docker-compose.yml` cho môi trường local, health check, volume, hướng
dẫn khởi chạy.

## Quyết định đã duyệt

- Docker là tiêu chuẩn bắt buộc (ADR-008). Không chỉ tạo file cho có —
  phải chạy thử và báo cáo kết quả thực tế.

## Phạm vi được phép sửa

`frontend/Dockerfile`, `admin/Dockerfile`, `backend/Dockerfile`,
`docker-compose.yml`, `.dockerignore`, `infrastructure/docker/README.md`,
`DOCKER_STANDARDS.md`.

## Yêu cầu kỹ thuật

- Dockerfile multi-stage (`deps` → `builder` → `runner`), base
  `node:20-alpine`, pnpm qua corepack, `pnpm install --frozen-lockfile`,
  runner cài `curl` cho healthcheck.
- Compose gồm: postgres:16-alpine, redis:7-alpine,
  meilisearch:v1.11, backend (3002), frontend (3000), admin (3001).
- Health check mọi service: postgres `pg_isready`, redis `redis-cli
  ping`, meilisearch `GET /health`, backend `GET /api/v1/health`,
  frontend/admin `GET /`.
- Backend `depends_on` postgres + redis (`service_healthy`).
- Named volumes: `postgres-data`, `redis-data`, `meilisearch-data`.
- Biến môi trường từ `.env` (mẫu trong `.env.example`).

## Tiêu chí nghiệm thu

1. Dockerfile + `docker-compose.yml` đúng chuẩn, health check đầy đủ.
2. `docker compose config --quiet` hợp lệ.
3. `docker compose up` chạy được + mọi service `(healthy)` — **MỤC NÀY
   UNVERIFIED trên máy dev của Muse** (containers không chạy được trên VM
   này — xem `DOCKER_STANDARDS.md` mục 5). Cần kiểm tra thật trên
   Windows của Henry / VPS / CI và cập nhật kết quả vào `CURRENT_STATE.md`.

## Cách kiểm thử

- `docker compose config --quiet` (đã chạy — hợp lệ).
- `docker compose up -d --build` + `docker compose ps` — CHƯA chạy được
  trên máy này; ghi rõ là UNVERIFIED, không được báo cáo ngược lại.
