## Mục tiêu

Khởi tạo monorepo `seecarauto/` với đúng cấu trúc đã thống nhất.

## Quyết định đã duyệt (áp dụng cho task này)

- Monorepo, Modular Monolith, API-first (ADR-002).
- `frontend/` Next.js (website khách hàng), `admin/` Next.js (trang quản
  trị), `backend/` NestJS (API độc lập), `packages/`, `infrastructure/`,
  `docs/`.

## Phạm vi được phép sửa

Tạo cấu trúc thư mục gốc và khung của 3 app + 4 package dùng chung.
Không làm tính năng kinh doanh.

## Yêu cầu kỹ thuật

- `frontend/`: Next.js 14.2.5 + TypeScript + Tailwind, App Router, `src/`.
- `admin/`: Next.js 14.2.5 + TypeScript + Tailwind, App Router, `src/`,
  chạy port 3001.
- `backend/`: NestJS 10 + TypeScript, port 3002, prefix `/api/v1`.
- `packages/typescript-config`, `packages/eslint-config`,
  `packages/shared` (types/hằng số), `packages/ui` (Modal/Toast/Tooltip/
  Button).
- Trang placeholder M00 cho frontend/admin (chưa có dữ liệu thật), backend
  có `GET /api/v1/health` và Swagger tại `/api/docs`.

## Tiêu chí nghiệm thu

1. Đúng cấu trúc thư mục đã thống nhất.
2. Cả 3 app đều build được.

## Cách kiểm thử

- `pnpm install` (root) thành công.
- `pnpm build` (turbo) thành công cho frontend, admin, backend, packages.
- `pnpm --filter backend test` (Jest) và
  `pnpm --filter @seecarauto/shared test` (Vitest) đạt.
