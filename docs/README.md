# Tài liệu dự án SEECARAUTO

Thư mục này chứa tài liệu dự án. Nguồn sự thật chung (single source of
truth) cho mọi cuộc chat task là **Project Handbook** trong
`project-management/` — mỗi task mới bắt đầu bằng việc đọc bộ tài liệu đó.

## Tài liệu

- `project-management/PROJECT_CHARTER.md` — mục tiêu, phạm vi, vai trò
- `project-management/MASTER_ROADMAP.md` — các milestone M00–M09
- `project-management/ARCHITECTURE_DECISIONS.md` — quyết định Henry đã duyệt
- `project-management/CODING_STANDARDS.md` — quy ước code, URL, bảo mật
- `project-management/UI_UX_STANDARDS.md` — quy chuẩn giao diện và tương tác
- `project-management/DOCKER_STANDARDS.md` — Docker, Compose, môi trường
- `project-management/TASK_BOARD.md` — trạng thái và phụ thuộc các task
- `project-management/CURRENT_STATE.md` — đang làm gì, đã xong gì, việc kế tiếp
- `project-management/CHANGELOG.md` — lịch sử thay đổi quyết định
- `project-management/tasks/` — Task Brief từng task (M00-01.md, M00-02.md, …)

Tài liệu chi tiết từng milestone sẽ được bổ sung khi milestone đó bắt đầu
(PRD/SRS, ERD, API Specification, Sitemap, Wireframe — theo kế hoạch của
ChatGPT).
